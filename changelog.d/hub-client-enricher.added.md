- **`HubClientEnricher` — highlight Hub clients named in a PDF** (`opencontractserver/pipeline/enrichers/hub_client_enricher.py`, constants `HUB_CLIENT_LABEL` in `opencontractserver/constants/annotations.py` and `HUB_CLIENTS_API_URL` / `HUB_CLIENTS_PER_PAGE` / `HUB_REQUEST_TIMEOUT_SECONDS` in `opencontractserver/constants/document_processing.py`). A new opt-in PDF enricher that downloads every page of Hub's client list (`GET https://hub.thoughtbot.com/api/clients`, 100 per page) with a personal token saved as the `hub_token` component secret, then appends a non-structural `HUB_CLIENT` token annotation wherever a client's `name` or `legal_name` appears among the PAWLs words (case-insensitive, whole words, punctuation at either end of a word ignored so `Acme Corporation,` and `("Acme")` match, longest name wins). Each highlight carries `link_url` (the client's Hub URL, so the existing click-through behaviour applies) and a `data` sidecar limited to the client's Hub `id`, `name`, `slug` and `url`. Matching happens in OpenContracts; no document text is sent to Hub. A missing token, a 401/403, any other non-200 answer from Hub (such as a 5xx), or Hub being unreachable or timing out logs a WARNING naming the cause (never the token) and adds nothing, so ingestion completes as before. Enable it by saving the token and assigning the enricher to `application/pdf` in System Settings. On an install that has turned off any component in the Component Library, also turn `HubClientEnricher` on there: a saved enabled list predates the enrichers and silently skips any enricher not in it. Tests: `opencontractserver/tests/test_hub_client_enricher.py`.
